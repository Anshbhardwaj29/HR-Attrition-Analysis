# HR-Attrition-Analysis
# Project 4: HR Employee Attrition Analysis

## 🎯 Objective
Performed a comprehensive statistical analysis on an HR workforce dataset to diagnose critical factors driving employee attrition, enabling data-backed decision-making for workforce planning and retention management.

## 🛠️ Tech Stack & Skills Learned
- **Language:** Python
- **Libraries:** Pandas, NumPy, Seaborn, Matplotlib
- **Statistical Methods:** Descriptive Statistics, Contingency Tables (Crosstab Analysis), Data Aggregation
- **Visualizations:** Stacked Histograms (KDE), Horizontal Bar Charts, Correlation Matrices

## 📊 Key Insights Captured
1. **Income Thresholds:** Stacked histograms clearly demonstrated that employee attrition significantly decreases as monthly income passes specific thresholds.
2. **Role-Based Risk:** Crosstab analysis isolated high-risk roles (e.g., Laboratory Technicians or Sales Executives) facing the highest turnover rates.
3. **Correlation Mapping:** Heatmaps statistically confirmed strong negative correlations between Attrition and both `MonthlyIncome` and `YearsAtCompany`.
